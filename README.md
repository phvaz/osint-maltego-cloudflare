# OSINT Infrastructure Mapping — Cloudflare

> Open Source Intelligence analysis using Maltego Community Edition  
> to map and correlate Cloudflare's public digital infrastructure.

## Objective

Map publicly available infrastructure data (domains, subdomains, IPs, ASNs)
using OSINT techniques and visual link analysis via Maltego CE.

## Tools

- Maltego Community Edition
- crt.sh (certificate transparency)
- Whois / RDAP
- DNS Lookup
- Public OSINT APIs
